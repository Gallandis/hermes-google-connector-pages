PRIVATE INTEGRATION

Hermes Google Workspace Connector

A private, single-user Google OAuth integration operated by Shayne Cooper.

Purpose

This connector allows the operator's locally managed Hermes Agent installation to access Google Workspace services when the operator explicitly requests an action.

Supported services may include Gmail, Google Calendar, Google Drive, Google Docs, Google Sheets, and Google Contacts.

Availability

This is not a public application or commercial service. It has no public registration, customer accounts, or third-party access. It is intended solely for the operator's own Google account.

Data handling

Google data is accessed only to carry out operator-requested tasks. The connector does not sell Google user data or use it for advertising.

For details, read the Privacy Policy.

Support

Support is available through the operator's GitHub profile. The OAuth consent screen also identifies the account's designated support email.
